# 數學任務站｜GitHub 公益學習版

這個資料夾可以直接發布到 GitHub Pages，不需要伺服器或付費服務。

## 已可使用的功能

- 七、八、九年級，共 30 個數學單元。
- 易／中／難三種程度，以及 10／15／20 題選擇。
- 隨機出題、同次不重複與最近五次題目冷卻。
- 與題意相符的數線、座標、圖表及幾何示意圖。
- 答錯提示、原因解析與重新作答。
- 不計分、不排名，只顯示總題數、完成題數與學習建議。
- 個人化錯題分析、優先補強單元與具體複習方法。
- AI 本機學習引導與六種建議問題（不連接外部 AI、不傳送文字）。
- 列印學習報告，並可由瀏覽器另存成 PDF。
- 春、夏、秋、冬四季風格與動物動畫。

## 目前刻意不啟用

GitHub Pages 只能發布靜態檔案，無法安全保管密碼、寄送驗證碼、執行資料庫或判斷教師權限。因此，本版不提供教育信箱登入、班級資料、教師派題、開發者審核及雲端報告。這些功能要等安全後端部署後再接上，不能用前端假登入取代。

本版的作答紀錄只用於這台裝置上的最近五次題目冷卻，不含姓名、信箱、學號或班級，也不會上傳。

## 發布步驟

1. 在 GitHub 建立一個公開的空白儲存庫，例如 `math-mission-station`。
2. 將本資料夾內的 `.github`、`site`、`.gitignore` 與 `README.md` 一起上傳到儲存庫的 `main` 分支。
3. 到儲存庫 **Settings → Pages**，將 **Source** 選成 **GitHub Actions**。
4. 到 **Actions** 查看 `Deploy GitHub Pages`；完成後，Pages 畫面會顯示公開網址。

工作流程會把 `site/` 發布為網站根目錄，所以首頁網址會自動開啟 `site/index.html`，不必修改檔案路徑。

## 本機預覽

可直接開啟 `site/index.html`，或用任何靜態網站伺服器預覽。正式判定請以 GitHub Pages 的 HTTPS 網址為準。

## 安全原則

- 不要把密碼、OTP、API 金鑰、學生名冊、報告資料庫或 `.env` 上傳到此儲存庫。
- 不要在前端 JavaScript 判斷真正的學生、教師或開發者權限。
- 日後接上後端時，身分驗證、角色授權與資料範圍檢查都必須在伺服器端完成。
