從一小題，走進數學

每個任務都會陪你經過「看懂題意、說出想法、嘗試作答、得到回饋」四個步驟。

「不會的地方不是失敗，而是下一個準備長出理解的小種子。」

1. 選擇年級任務

2. 選擇想複習的單元

一次只練一個單元也可以；選「全部單元」才會進行整組練習。

3. 選擇挑戰程度

4. 選擇題數

選擇全部單元可進行 10、15、20 題練習；單一單元依題庫數量提供練習。

5. 遊戲規則

  1. 每題先選答案，再看結果。
  2. 答對 +100 分；使用提示後答對 +70 分。
  3. 答錯不扣分，先看題目下方的提醒，再重做。
  4. 完成後可向 AI 助手提問，並查看個人學習分析。
