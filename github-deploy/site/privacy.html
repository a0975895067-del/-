GitHub 公益預覽版隱私說明

版本：2026-09-02

這個公開版本會做什麼？

本頁提供七、八、九年級數學匿名練習、提示、解析、學習小結及由瀏覽器建立的 PDF 報告。

這個公開版本不會做什麼？

  • 不提供帳號登入、電子郵件驗證碼、教育雲端身分驗證或自動編班。
  • 不要求輸入姓名、學號、班級、座號、教師資料或私人聯絡方式。
  • 不把作答紀錄、學習分析或 PDF 報告上傳到 GitHub。
  • 不提供教師後台、開發者後台或跨裝置資料同步。

資料留在哪裡？

作答狀態只在目前瀏覽器頁面中暫時使用；重新整理或關閉頁面後可能消失。下載的 PDF 只會儲存在使用者自行選擇的裝置位置。

正式學校版

教育信箱、驗證碼、班級、教師權限與雲端報告必須另行部署經校方核准的 HTTPS 後端，完成法規、契約、權限與資安檢查後才能啟用；GitHub Pages 不承擔這些功能。
